## 一、目标

构建一个**承认治理自身也不完备**的多角色协作系统，作为软件开发的辅助基础设施。

### 1.1 核心目标

1. **可演化**：系统必须能在不破坏核心契约的前提下持续演化（承接治理哲学的「治理可演化」）。
2. **可追溯**：每个治理动作都可追溯到哲学锚 + decided_by + falsifiable。
3. **可证伪**：每条治理规则都有 falsifiable 条件 + 时间窗口，避免「理论正确但无法验证」。
4. **可协作**：4 分类（决策者 / 设计者 / 验收者 / 实现者）分工明确，流水线不可跳层。

### 1.2 成功标准

| 指标 | 目标 | 时间窗口 |
|:--|:--|:--|
| 完整验证流水线 | 17/17 全绿 | 上线后 1 个月 |
| 决策可证伪率 | > 80% 的决策带 falsifiable | 上线后 6 个月 |
| 4 分类机械判定覆盖率 | 100% | 上线后 1 个月 |
| 流水线跳层次数 | 0 | 持续 |
| 治理动作可追溯率 | 100% | 持续 |

## 二、非目标（NOT Goals）

明确**不做什么**，避免范围蔓延：

1. **不替代人类决策**——LLM 不写决策契约；decided_by 必填人类标识符。
2. **不接入商业 LLM 私有接口**——只接 MiniMax-M3 / DeepSeek / Claude / OpenAI 等公开 API。
3. **不替代软件工程实践**——本系统辅助开发，不替代工程师的代码评审。
4. **不承诺完整自治**——阶段 B（自动优化期）的自动巡检 + 自动演化回路可关闭，保留人类介入接口。
5. **不发愁国际化**——v3 仅中文；多语言留待 v4+。
