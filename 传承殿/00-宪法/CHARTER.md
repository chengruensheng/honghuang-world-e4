## 一、目标

构建一个**承认治理自身也不完备**的多角色协作系统，作为软件开发的辅助基础设施。

### 1.1 核心目标

1. **可演化**：系统必须能在不破坏核心契约的前提下持续演化（接司衡"治理可演化"）。
2. **可追溯**：每个治理动作都可追溯到哲学锚 + decided_by + falsifiable。
3. **可证伪**：每条治理规则都有 falsifiable 条件 + 时间窗口，避免"理论正确但无法验证"。
4. **可协作**：4 分类（道祖/圣人/准圣/大罗金仙）分工明确，流水线不可跳层。

### 1.2 成功标准

| 指标 | 目标 | 时间窗口 |
|:--|:--|:--|
| 一键全验 | 10/10 全绿 | 上线后 1 个月 |
| 决策可证伪率 | > 80% 的决策带 falsifiable | 上线后 6 个月 |
| 4 分类机械判定覆盖率 | 100% | 上线后 1 个月 |
| 流水线跳层次数 | 0 | 持续 |
| 治理动作可追溯率 | 100% | 持续 |

## 二、非目标（NOT Goals）

明确**不做什么**，避免范围蔓延：

1. **不替代人类决策**——LLM 不写决策契约；decided_by 必填人类标识符。
2. **不提供 UI/UX 框架**——按 AGENTS § 14，UI 权重最低；核心优先于门面。
3. **不接入商业 LLM 私有接口**——只接 MiniMax-M3 / DeepSeek / Claude / OpenAI 等公开 API。
4. **不替代软件工程实践**——本系统辅助开发，不替代工程师的代码评审。
5. **不承诺完整自治**——乙阶段（自动优化期）的巡世 + 进化环可关闭，保留人类介入接口。
6. **不发愁国际化**——v3 仅中文；多语言留待 v4+。
