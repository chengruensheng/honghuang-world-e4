### 1.2 6 层源码结构（kebab-case + 类型后缀）

> 决策锚：260831-六层命名格式统一（唯一事实源）

| 层 | 格式 | 后缀 | 示例 |
|:--|:--|:--|:--|
| 维度 | `XX`（2 字） | 无 | `鸿蒙` |
| 域 | `XXXX-域`（4 字连写，优先 4 字次 2 字） | `-域` | `基础设施-域` `律法-域` |
| 府 | `XXXX-府`（4 字连写，优先 4 字次 2 字） | `-府` | `实时服务-府` `工具调用-府` `规则-府` |
| 殿 | `XX-XX-殿`（三段式） | `-殿` | `实时-服务-殿` `命令-调度-殿` |
| 阁 | `XX-XX-阁`（三段式） | `-阁` | `服务-配置-阁` `注册-登记-阁` |
| 园 | `XX-XX-园`（三段式） | `-园` `-数据` `-配置` `-模板` `-脚本` `-资源` | `配置-落地-园` `会话-归档-数据` |

**关键差异**：域/府 4 字连写（一眼看出「是什么」）；殿/阁/园 2 字拆 2 段（三段式，组合多、不重名）。

**目录全用连字符（-）且无空格**，不用下划线。禁止 `基础设施 - 域`（带空格）。

### 1.3 命名语义判据（260831-六层命名格式统一）

**空间隐喻**：维度=世界 → 域=地域 → 府=府邸 → 殿=大殿(门面) → 阁=深阁(动作) → 园=后花园(落地)。

**域府不同名 + 祖孙不同名**：相邻两层不得同名。例如：
- ✗ 「规则-域」/「规则-府」→ 域府同名，违规
- ✓ 「律法-域」/「规则-府」→ 不同名 ✓
- ✗ 「状态机-殿」/「状态机-阁」/「状态机-园」→ 祖孙同名，违规

门禁实现：验证-命名唯一性.ps1 规则 4「祖孙语义重复」+ 规则「域府不同名」+ 架构校验.rs「同层命名唯一」。

## 三、源码结构模板

### 3.1 标准府结构（鸿蒙/基础设施-域/X-府/）

```text
X-府/
├── Cargo.toml          ← 继承 workspace
├── 入口.rs            ← lib 根（中文文件名，替代 src/lib.rs）
├── 服务.rs            ← 顶层服务 trait
├── 服务注册表.rs      ← 顶层数据结构
├── 错误.rs            ← 顶层错误定义
├── 元数据.rs          ← 顶层元数据
├── README.md          ← 府级说明
└── Y-殿/            ← 殿（模块.rs 桥接）
    ├── 模块.rs
    └── Z-阁/        ← 阁
        ├── 模块.rs
        └── W-园/    ← 园
```

### 3.2 Cargo.toml（府级）模板

```toml
[package]
name = "拼音_xxx_fu"        # 必须 snake_case ASCII
version = "0.1.0"
edition.workspace = true
rust-version.workspace = true
authors.workspace = true
license.workspace = true

[dependencies]
# 府级依赖

[lib]
# 关键：用 path 属性桥接到中文文件名入口.rs
path = "../入口.rs"
name = "拼音_xxx_fu"
```

### 3.3 入口.rs（府级）模板

```rust
//! X-府（中文名 + 一句话本质）
//!
//! 决策锚：02-概念/XX/XX.md
//! 关联文档：04-设计/数据模型/XX.md

#![allow(non_snake_case)]  # 允许中文标识符

// === 各殿 ===
pub mod Y_殿;
pub mod Z_殿;

// === 顶层导出 ===
pub use Y_殿::SomeStruct;
pub use Z_殿::AnotherStruct;
```

### 3.4 模块.rs（殿级 / 阁级）模板

```rust
//! X-殿 / Y-阁（中文名）
//!
//! 决策锚：02-概念/XX/XX.md

// 只 pub mod 子层，不写实现
pub mod Z_阁;
pub mod W_园;
```

### 3.5 园文件模板

```rust
//! X-园（具体实现）
//!
//! 决策锚：02-概念/XX/XX.md
//! 关联文档：04-设计/数据模型/XX.md
//! 实现手段：流式 / 多轮 / 原子 / 批量 / 并行 / 缓存 / 降级 / 兜底 / 分块 / 增量 / ...

// 实际代码 + 注释
// 必须包含：
// - 决策锚注释（接 02-概念/XX/XX.md）
// - 关联文档路径注释
// - 实现手段词（必含）
// - 哲学层 → 概念层 → 工程层 三段推导（如适用）
```
