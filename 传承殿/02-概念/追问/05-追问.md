# 05-追问.md

> **概念·法**——不是"grilling engine"，是"治理上游要先收敛意图"。

## 一、哲学层（为什么）

为什么需要追问？因为**没有意图收敛就没有治理**。

- 模糊意图 → LLM 自由发挥 → 结果不可预测
- 收敛意图 → LLM 在边界内工作 → 结果可验证

司衡追问引擎的哲学：**治理的起点是让用户明确自己的意图**。LLM 不能替你做这个决定。

## 二、概念层（是什么）

### 4 问题（对应道二/顺因/有度/知止）

```
道二 → 你的意图是什么？（意图先于代码）
顺因 → 这个提案的因果方向是什么？
有度 → 规则数 / 严格度是否与风险成正比？
知止 → 哪些事情不做？
```

### 与"grilling engine"命名的差异

| "grilling engine" 命名 | 追问概念 |
|:--|:--|
|"engine"|"机制"，engine 暗示自动，机制更准确|
|"grilling"|"追问"，是 meta 层而非数据层|
|"自调 LLM"|"生成提示词"，不调 LLM 生成内容|

### 三条铁律

1. **不调 LLM 生成内容**——司衡"不生成只验证"原则
2. **生成提示词而非答案**——决定权在界主
3. **4 问题一次性追问**——不允许轮询（Solo 模式）
