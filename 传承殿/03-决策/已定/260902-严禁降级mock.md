## 一、为什么（治理哲学）

项目负责人的原话：

> 默认 = 真实，无 key 严禁降级。这是为了预防未来人类没有看到的期间，
> 因为降级导致生成垃圾模板文件，导致工作区域污染，也影响人类判断有没有出问题。

核心推理：

1. **AI 自主运行的间隙，人类不在场**——若系统在此间隙静默降级 mock，会产出「看似成功」的假结果。
2. **假结果落盘 = 工作区污染**——mock 生成的垃圾模板文件混入真实资产，人类事后无法分辨哪些是真实产出、哪些是测试残留。
3. **污染侵蚀可判断性**——人类唯一的介入方式是看异常摘要；被污染的审计流会让「有没有出问题」变得不可判断。
4. **fail-loud 是对的**——宁可让人类看到「报错」（退出码 4），也不能让系统「假装成功」。报错 = 人类知道要处理；假装成功 = 污染悄悄扩散。

## 二、是什么（规则定义）

| 场景 | 行为 |
|:--|:--|
| 未设置 `LLM_BACKEND`（默认） | 走**真实 API**，严禁降级 mock |
| `LLM_BACKEND=real` | 走真实 API |
| `LLM_BACKEND=mock` | 仅显式允许（测试/演示专用） |
| 无 `LLM_API_KEY` + 真实/默认 | **fail-loud 报错退出码 4**，不产出任何落盘 |
| mock 模式运行 | 读写走**临时隔离库**（`%TEMP%`），**绝不写入默认真实库** |

## 三、怎么做（工程落地）

1. `后端解析.rs`：三态枚举（真实/Mock/默认），`默认` 语义 = 真实（拼写错误也归默认=真实）。
2. `跑流水线_按后端`：真实/默认 → `从环境变量构造()` 失败即 `return 命令结果::失败(退出码4)`，零落盘。
3. `跑流水线_按连接`：回填库 `None`（mock）时读库走临时隔离库，不回退默认库——**根治 mock 测试污染真实审计流**（实测修复前：mock 一次事件流 101→104；修复后 104→104）。
4. 回归测试 `测试_mock_不污染默认真实库` 防未来改回去。
5. AGENTS.md 强制规则第 15 条收录本铁律（19 条规则体系）。
