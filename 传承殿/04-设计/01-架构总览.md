```
太初 ─────┐
          ├─→ 本体维度（域） ─→ 府 ─→ 殿 ─→ 阁 ─→ 园
混沌 ─────┤                              ↑
          │                              │
乾坤 ─────┤   工具链维度（域） ─→ 服务    │
          │                  （可插拔）  │
```

## 二、六层结构与九根的交叉

每个根维度下，按六层组织：
- **域**：语义分组（如"基础设施 - 域"）
- **府**：lib crate（唯一编译单位，Service Definition 暴露点）
- **殿/阁/园**：层层递进（能力只在园落地）

### 服务清单（按九根维度 + 六层）

### 鸿蒙（核心基础设施）

| 服务 | 职责 |
|:--|:--|
| 插件上下文 | Service Definition 注册表 + 查找 |
| 事件总线 | 三类事件 + Waterfall/Serial |
| 记忆承载 | 36 格位 + 3 档投影 + 3 源记录 |
| 状态共享 | 进程级状态读写 |
| 观测探针 | 事件通道埋点 |
| 日志记录 | tracing 定制封装 |
| 流水线驱动 | 多阶段状态机（决策者→设计者→实现者→验收者→决策者） |
| 任务执行 | LLM 池 + 工具循环 + 4 分类角色卡 |
| 配置管理 | 密钥/模型配置注入 |

## 三、4 分类的工程落位

```
决策者 ─→ 流水线驱动 - 府/天层-主控-殿/决策者级/
         ├── 追问引擎（02-概念/追问/05-追问.md）
         ├── 化要求 / 派遣 / 最终裁决 / 定档
         └── 多 LLM 投票（关键决策）

设计者 ─→ 任务执行 - 府/角色-卡册-殿/设计者卡/
         ├── 设计 / 评审
         └── 评审四元组

验收者 ─→ 任务执行 - 府/角色-卡册-殿/验收者卡/
         ├── 六维验收（前 4 维机械 + 后 2 维 LLM）
         └── 验收驳回决策（独立判定）

实现者 ─→ 任务执行 - 府/角色-卡册-殿/实现者卡/
             ├── 实现（按领域分工：性能/数据/接口/监控）
             └── 路径前缀校验（不越领域）
```
