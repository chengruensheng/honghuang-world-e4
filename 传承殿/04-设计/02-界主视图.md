# 02-界主视图.md

> **设计层·术**——界主视图 = 「人在环外」的唯一窗口。它是产品的门面，也是三条铁律（人类只看异常 / 玉玺终裁 / 白箱可见）的实物化。
> 定位：本设计稿是「界面」的认知锚点，回答「界主通过什么看见世界、通过什么掌控世界」。所有界面实现须对本设计校准。

## 一、定位：界主视图是什么

界主视图不是"仪表盘"，不是"控制台"，更不是"聊天窗口"。它是：

> **世界正常自转时，界主几乎什么也看不见；世界需要界主时，界主第一眼就能看见。其余任何时候，界主都能打开白箱看清全貌。**

一句话：**静默为常态，异常才显形，玉玺是唯一裁决，白箱是永不关闭的后门。**

它把宪法里三条铁律翻译成人能看懂、能用、能信的东西：

| 铁律（宪法） | 界主视图的实物化 |
|:--|:--|
| 基线 2「信息洪流是旧仓失败根因」 | **静默优先**：正常时只有一行"世界自转中" |
| 基线 3 / 禁止 4「人类只看异常、只通过视图介入」 | **异常门**：唯一默认可见的内容 = 异常 |
| 「人类是最终权威（decided_by / 玉玺）」 | **玉玺**：界主的"确认"动作 = 盖印 |
| 「全程白箱可见——可以不要，但不能没有」 | **白箱**：永远可展开的全貌视图 |

## 二、五条设计原则（从世界观推导，不借词）

### 原则 1：静默优先（顺势）

世界正常时，界主视图**不应该热闹**。每一条"正常"信息堆在界主眼前，都是在重蹈司衡基线 2 点名的"信息洪流"覆辙。

- ✓ 正确：世界自转正常 → 界主只看到一行"世界自转中 · 17 门禁全绿 · 债务 0"
- ✗ 错误：把 4 分类流水线每一步、每一条日志都实时刷给界主看

**静默是能力，不是缺失。** 界主放手（人在环外）的前提，是界面允许界主不看。

### 原则 2：异常驱动（损补）

界主的第一眼，永远落在"需要界主"的地方。异常 = 机器的确定性程序处理不了、必须人类介入的事：

| 异常类型 | 来源 | 界主看到什么 |
|:--|:--|:--|
| 验收打回 | 4 分类流水线（准圣→大罗） | 什么任务被打回、打回理由、第几轮 |
| 循环超限升级 | 流水线状态机（打回 ≥3） | 已升级道祖终裁，待界主裁决 |
| 债务超限 | 记忆账本（已交付−已归档） | 欠多少、已降级为快照待提炼 |
| LLM 故障 | 模型连接（fail loud） | 故障类型（网络/超时/非2xx/额度） |
| 门禁失败 | 一键全验 | 哪一项门禁红、阻碍了哪次交付 |
| 文档污染 | 文档收割门 | 哪个 .md 被判污染、已回滚 |

每条异常只显示**三件事**：什么 / 在哪 / 机器已经自动做了什么 + 是否待界主裁决。不显示原始日志（禁止 4）。

### 原则 3：玉玺终裁（道）

界主对世界的一切"确认"，只有一种动作：**盖玉玺**。盖印 = 该产出/决策升为「来源=人类 + decided_by=界主」，在记忆层优先级最高（盖印 > 人类写入 > LLM 写入）。

- 玉玺不是"点赞"，是**权威分层**在界面上的一枚印。
- 界主的驳回，同样是一次裁决，入事件流、可追溯。

### 原则 4：白箱可开（知止）

"可以不要，但不能没有"——界主**不一定看**，但**随时能看**。白箱是永不关闭的后门：

- 36 格位（记忆全貌）
- 事件流（hash 链，append-only 时序事实）
- 4 分类流水线（当前态 / 过程态）
- 一键全验 17 门禁（当前状态）
- 世界快照（crate 数 / 测试数 / git 近况）

### 原则 5：意图唯一入口（顺因）

界主对世界**只做两件事**：① 用中文说"要什么"（意图）；② 对异常盖玉玺（裁决）。**其余一切是世界自己的事。**

界主说"要什么"，不说"怎么实现"——这是意图驱动的界面化表达。

## 三、信息架构：五区（按"界主需要看的程度"分层）

```
┌─────────────────────────────────────────────────────────┐
│  Z0 意图    [ 用中文说：你要世界做什么？        ]  [发布]  │
├─────────────────────────────────────────────────────────┤
│  Z1 异常门   （默认视图 · 静默为常态）                      │
│             · 世界自转中 —— 一切正常时只有这一行           │
│             · 或：N 条异常，按「需界主裁决」置顶            │
├─────────────────────────────────────────────────────────┤
│  Z2 玉玺     （待界主裁决的决策队列）                       │
│             [决策摘要]  [✓ 盖玉玺]  [✗ 驳回]              │
├─────────────────────────────────────────────────────────┤
│  Z3 白箱     （可折叠 · 永不关闭的后门）                    │
│             36格位 │ 事件流 │ 流水线 │ 门禁 │ 世界快照      │
├─────────────────────────────────────────────────────────┤
│  Z4 世界自转  （人在环外的证据：世界在自主做什么）            │
│             最近提交 / 最近回填 / 最近验收 / 最近收尾        │
└─────────────────────────────────────────────────────────┘
```

### Z0 意图（Intention）

- 一个输入框 + 一个「发布」按钮。
- 发布 = 触发道祖级「化要求」（4 分类流水线入口）。
- 界主只写"要什么"，不写"怎么做"。

### Z1 异常门（Exception Gate）—— 默认视图

- **静默态**：一切正常 → 一行"世界自转中 · 17 门禁全绿 · 债务 0 · 最近收尾 HH:MM"。
- **显形态**：有异常 → 异常列表，按「待界主裁决」置顶，其余按时间倒序。
- 每条异常：`类型 · 位置 · 机器已自动处理（或待界主裁决）· 时间`。

### Z2 玉玺（Seal）—— 界主裁决队列

- 待界主裁决的决策/产出，逐条列出。
- 每条：决策摘要 + `[✓ 盖玉玺]` `[✗ 驳回]`。
- 盖印后：该条升为「来源=人类」，进入事件流，从队列消失。

### Z3 白箱（White Box）—— 全貌后门

- 五页签：`36格位` / `事件流` / `流水线` / `门禁` / `世界快照`。
- 只读，不在此操作（操作在 Z0/Z2）。

### Z4 世界自转（Self-rotation）—— 人在环外的证据

- 展示世界在界主不介入时自主做的事：最近提交（git）、最近回填（记忆）、最近验收、最近收尾。
- 这一区是"人在环外"是否成立的可视证明。

## 四、交互流：界主的三种姿势

1. **发布意图**（Z0）→ 世界自动走 4 分类流水线 → 界主不再介入，直到：
2. **看异常**（Z1）→ 有需裁决的异常 → 界主进入：
3. **盖玉玺**（Z2）→ 确认或驳回 → 世界继续自转。

任意时刻，界主可：
4. **开白箱**（Z3）→ 看 36 格位 / 事件流 / 流水线 / 门禁 / 快照，看完关闭。

## 五、视觉语言与命名

### 视觉基调：水墨为底，异常为红

- 底：深色水墨（黑/玄），呼应"混沌/洪荒"；世界安静时界面近乎留白。
- 异常：朱砂红（朱/赤），只有异常才着色——**颜色本身就是"只看异常"的视觉化**。
- 玉玺：印章红方框 + "界主"二字，盖印是唯一的高亮动作。
- 白箱：半透明浅色层，暗示"后门/底层"，而非主界面。

### 命名（哲学推导，不借词）

| 名 | 推导 | 不借的词 |
|:--|:--|:--|
| 界主视图 | 界主 = 世界唯一人类，视图 = 唯一窗口 | dashboard（仪表盘）|
| 异常门 | 异常经"门"自动顶到界主，门开则显 | notification center |
| 玉玺 | 界主权威凭证，盖印即升格 | approve / confirm |
| 白箱 | 与黑箱相对，可看内部 | debug panel |
| 世界自转 | 人在环外，世界自主运转 | activity feed |

## 七、实现路线（三步）

1. **预览原型（本会话）**：以动态 Cordis 插件在 DSH 页面内渲染界主视图，接真实数据（git / 记忆库 / 一键全验），供界主"提前看见"并拍板。
2. **乾坤·界面域（落盘）**：按本设计稿，在 `乾坤/界面呈现-域/界面视图-府/` 落地正式界面（六层结构：域→府→殿→阁→园），接 `shijie` 引擎与记忆库。
3. **自举开发**：用 `shijie` 的流水线开发界主视图的后续功能，形成"用它开发它自己"闭环。

## 八、falsifiable

- 上线 1 个月：世界正常自转时，界主每日查看界主视图的时长 < 5 分钟（静默优先成立）。
- 上线 1 个月：异常置顶准确率 = 100%（该顶到界主的异常，无一条被淹没在正常信息里）。
- 上线 3 个月：界主通过 Z0 发布意图 → 世界交付 → 界主盖玉玺，全程不需要界主看任何代码或原始日志。
- 上线 3 个月：白箱展开到看清任一格位/任一条事件流的耗时 < 10 秒（白箱可开）。
