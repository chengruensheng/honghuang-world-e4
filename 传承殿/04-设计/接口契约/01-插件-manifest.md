# 01-插件-manifest.md

> **插件契约**——每个插件必须有 manifest，描述接口 + 依赖 + 副作用 + 不可改。

## 一、Manifest 格式（TOML）

```toml
# 插件唯一标识
名称 = "插件标识"

# 实现哪些契约（多个）
实现 = ["契约A", "契约B"]

# 依赖的其他插件（可枚举）
依赖 = ["插件X", "插件Y"]

# 副作用枚举
副作用 = "none | mutating | external"

# 调用结果是否 frozen
不可改 = true

# 资源限制
[资源限制]
内存上限 = "256MB"
超时 = "30s"
并发 = 1

# 监控埋点
[监控]
埋点 = ["调用次数", "失败率", "平均耗时"]
告警阈值 = { 失败率 = 0.05, 平均耗时 = "5s" }

# 决策契约
[决策契约]
decided_by = "界主"
falsifiable = "上线 3 个月，插件替换不影响其他插件的成功率 > 95%"
implements = "法·可演化（局部替换不影响整体）"
```

## 二、字段说明

| 字段 | 类型 | 必填 | 说明 |
|:--|:--|:--|:--|
| **名称** | string | ✓ | 插件唯一标识 |
| **实现** | array | ✓ | 实现哪些契约（trait 名称） |
| **依赖** | array | ✓ | 依赖的其他插件（拓扑序校验） |
| **副作用** | enum | ✓ | none（无副作用）/ mutating（修改文件或状态）/ external（调用外部） |
| **不可改** | bool | ✓ | true = 调用结果 frozen outcome |
| **资源限制** | object | ✗ | 内存/超时/并发 |
| **监控** | object | ✗ | 埋点 + 告警阈值 |
| **决策契约** | object | ✓ | decided_by + falsifiable + implements |

## 三、可并行性判定

**`副作用 = "none"` 才允许并发**：
- ✅ 探查类（read / grep / glob / list）天然可并行
- ❌ 编辑类（write / edit）有副作用，禁止并行
- ❌ 执行类（run_command / run_test）状态不确定，禁止并行

## 四、加载流程

```
启动 → 扫描 plugins/*/manifest.toml →
   解析每个 manifest → 校验 schema + 名称唯一性 + 依赖拓扑 →
   注册到内存注册表 → 暴露 插件清单() 给编排器
```

## 五、运行时校验

- 副作用检查：mutating 类不允许 `tokio::join!` 并发
- 不可改检查：frozen 结果任何修改尝试都拒绝
- 资源限制：超时/内存超限自动终止 + 告警

## 六、决策契约字段

每个插件必须有 `[决策契约]` 段：
- **decided_by**：人类标识符（不能是 LLM 名）
- **falsifiable**：可证伪命题
- **implements**：哲学锚（道/法/术/鉴/应/元 或五法）
