# 01-记忆.md

> **数据模型·记忆**——36 格位轴（6 范畴 × 6 阶段）× 3 档 × 3 来源，三维正交。

## 一、数据模型

```rust
/// 6 范畴（范畴维度）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum 范畴 { 目标, 规则, 自我, 程序, 世界, 经历 }

/// 6 阶段（阶段维度，每个本质都经过）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum 阶段 { 提案, 审阅, 拍板, 实施, 验收, 归档 }

/// 3 档位（时间维度）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum 档位 { 经档, 权档, 行档 }

/// 3 来源
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum 来源 { 代码, LLM, 人类 }

/// 36 格位总数（派生值，不硬编码）
pub const 范畴数: usize = 6;
pub const 阶段数: usize = 6;
pub const 格位总数: usize = 范畴数 * 阶段数;  // 36

/// 格位路径：支持 36 格位下的细分（继承父 + 更加具体）
/// 例：`目标/拍板/传承殿/9根维度` 是 `目标/拍板` 的细分
pub type 格位路径 = Vec<String>;

/// 构造格位路径（自动继承父的范畴 + 阶段）
pub fn 格位路径_构造(范畴: 范畴, 阶段: 阶段, 细分路径: &[&str]) -> 格位路径 {
    let mut 路径 = vec![format!("{:?}", 范畴), format!("{:?}", 阶段)];
    路径.extend(细分路径.iter().map(|s| s.to_string()));
    路径
}

/// 提取格位路径的"父格位"（前 2 段 = 36 格位之一）
pub fn 格位路径_父格位(路径: &格位路径) -> Option<(范畴, 阶段)> {
    if 路径.len() < 2 {
        return None;
    }
    let 范畴 = match 路径[0].as_str() {
        "目标" => 范畴::目标,
        "规则" => 范畴::规则,
        "自我" => 范畴::自我,
        "程序" => 范畴::程序,
        "世界" => 范畴::世界,
        "经历" => 范畴::经历,
        _ => return None,
    };
    let 阶段 = match 路径[1].as_str() {
        "提案" => 阶段::提案,
        "审阅" => 阶段::审阅,
        "拍板" => 阶段::拍板,
        "实施" => 阶段::实施,
        "验收" => 阶段::验收,
        "归档" => 阶段::归档,
        _ => return None,
    };
    Some((范畴, 阶段))
}

/// 记忆条目：三维正交 + 格位细分路径
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct 记忆条目 {
    pub id: 记忆ID,
    pub 格位路径: 格位路径,   // 36 格位 + 可选细分（≥ 2 段，前 2 段是 36 格位之一）
    pub 档位: 档位,           // 3 时间
    pub 来源: 来源,           // 3 来源
    pub 内容: String,
    pub 证据: Vec<证据ID>,
    pub decided_by: String,
    pub falsifiable: Option<可证伪条件>,
    pub implements: String,   // 哲学锚
    pub hash: Hash,
    pub 软放弃: bool,         // 是否软放弃（默认 false）
}
```

## 二、三层防护的工程实现

### 2.1 按本质物理隔离

不同本质用不同类型（编译期隔离）：

```rust

impl 规则条目 { pub fn 验证规则(&self) -> 世界 { ... } }
```

### 2.3 永驻加载（防遗忘）

```rust
/// 启动时加载 36 行永驻摘要到 AI 上下文
pub fn 启动时加载(上下文: &mut AI上下文) {
    上下文.注入(永驻摘要());  // 36 行摘要
}

/// 永驻摘要：每个范畴 + 阶段的经档条目压缩成 1 行
pub fn 永驻摘要() -> String {
    let mut 摘要 = String::new();
    for 范畴 in 所有范畴() {
        for 阶段 in 所有阶段() {
            if let Some(条目) = 查询经档(范畴, 阶段) {
                if !条目.软放弃 {
                    摘要.push_str(&format!("{}：{}
", 范畴_阶段(范畴, 阶段), 条目.摘要));
                }
            }
        }
    }
    摘要
}

/// 软放弃：AI 显式声明放弃某个永驻条目（可恢复）
pub fn 软放弃(id: 记忆ID, decided_by: &str, 理由: String) -> 世界结果<()> {
    if decided_by.is_empty() {
        return Err(错误::缺失决策者);
    }
    标记软放弃(id, decided_by, 理由);
    Ok(())
}
```

## 三、范畴判定的程序化规则

按"验证分离"原则：写入接口（程序）做校验，LLM 只生成内容——LLM 不能决定本质。

```rust
/// 范畴判定（程序化规则）
pub fn 判定本质校验(
    内容: &str,
    声称本质: 范畴,
    声称阶段: 阶段,
) -> 世界结果<()> {
    // 1. 调用者必须显式指定范畴
    // 2. 程序按规则校验"这是不是合理"
    if !本质阶段合法性(声称本质, 声称阶段) {
        return Err(错误::本质阶段不匹配);
    }
    if !内容本质一致(内容, 声称本质) {
        return Err(错误::内容本质不一致);
    }
    Ok(())
}

/// 内容本质一致性（启发式）
fn 内容本质一致(内容: &str, 声称本质: 范畴) -> bool {
    match 声称本质 {
        目标 => 内容.contains("TODO") || 内容.contains("计划") || 内容.contains("未来"),
        规则 => 内容.contains("必须") || 内容.contains("禁止") || 内容.contains("约束"),
        自我 => 内容.contains("我是") || 内容.contains("身份") || 内容.contains("角色"),
        程序 => 内容.contains("代码") || 内容.contains("函数") || 内容.contains("实现"),
        世界 => 内容.contains("环境") || 内容.contains("状态") || 内容.contains("系统"),
        经历 => 内容.contains("已发生") || 内容.contains("历史") || 内容.contains("过去"),
    }
}

/// 本质 × 阶段合法性
fn 本质阶段合法性(本质: 范畴, 阶段: 阶段) -> bool {
    match 本质 {
        目标 => matches!(阶段, 提案 | 拍板 | 实施),
        规则 => matches!(阶段, 提案 | 审阅 | 拍板),
        自我 => matches!(阶段, 提案 | 拍板),
        程序 => matches!(阶段, 提案 | 审阅 | 实施 | 验收),
        世界 => matches!(阶段, 提案 | 验收),
        经历 => matches!(阶段, 提案 | 实施 | 验收 | 归档),
    }
}
```

## 四、写入接口（强制 4 维正交）

```rust
pub trait 记忆写入 {
    fn 写入(
        &mut self,
        范畴: 范畴,
        阶段: 阶段,
        档位: 档位,
        来源: 来源,
        内容: String,
        证据: Vec<证据ID>,
        decided_by: &str,
    ) -> Result<记忆ID, 错误>;
}

impl 记忆写入 for 记忆承载 {
    fn 写入(
        &mut self,
        范畴: 范畴,
        阶段: 阶段,
        档位: 档位,
        来源: 来源,
        内容: String,
        证据: Vec<证据ID>,
        decided_by: &str,
    ) -> Result<记忆ID, 错误> {
        // 1. 校验 decided_by
        if decided_by.is_empty() { return Err(错误::缺失决策者); }
        // 2. 范畴判定校验
        判定本质校验(内容, 范畴, 阶段)?;
        // 3. 档位权限校验
        if !档位_允许写入(档位, 来源) { return Err(错误::写入权限不足); }
        // 4. 落盘 + hash
        let 条目 = 记忆条目 { /* ... */ };
        self.落盘(&条目)?;
        Ok(条目.id)
    }
}
```
