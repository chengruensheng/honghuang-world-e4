# 01-流水线.md

> **状态机设计**——4 阶段不可跳层不可反序。

## 一、状态定义

```rust
pub enum 流水线阶段 {
    待化要求,           // 道祖入口
    化要求中,           // 道祖化要求
    待设计,             // 已化要求，待圣人
    设计中,             // 圣人设计
    待实现,             // 已设计，待大罗
    实现中,             // 大罗金仙实现
    待验收,             // 已实现，待准圣
    验收中,             // 准圣验收
    待终裁,             // 已验收，待道祖
    终裁中,             // 道祖终裁
    已定档,             // 终态
    已打回待重做,       // 中间态
    循环超限升级,       // 异常态
}
```

## 二、状态转移规则

### 正向转移（顺因）

```
待化要求 → 化要求中 → 待设计 → 设计中 → 待实现
   → 实现中 → 待验收 → 验收中 → 待终裁 → 终裁中 → 已定档
```

### 反向转移（打回）

```
验收中 → 已打回待重做 → 待实现
（仅准圣级可触发）
```

### 循环超限升级

```
验收中 → 已打回待重做 → 待实现 → ... 循环 3 次 →
   循环超限升级 → 终裁中
（道祖人工裁决）
```

## 三、状态转移函数

```rust
pub fn 推进(当前: 流水线阶段, 事件: 事件) -> Result<流水线阶段, 错误> {
    match (当前, 事件) {
        (待化要求, 事件::化要求完成(_)) => Ok(化要求中),
        (化要求中, 事件::要求书就绪(_)) => Ok(待设计),
        (待设计, 事件::设计开始) => Ok(设计中),
        (设计中, 事件::方案就绪(_)) => Ok(待实现),
        (待实现, 事件::实现开始) => Ok(实现中),
        (实现中, 事件::产物就绪(_)) => Ok(待验收),
        (待验收, 事件::验收开始) => Ok(验收中),
        (验收中, 事件::验收通过) => Ok(待终裁),
        (验收中, 事件::验收打回(_)) => Ok(已打回待重做),
        (待终裁, 事件::终裁开始) => Ok(终裁中),
        (终裁中, 事件::定档完成(_)) => Ok(已定档),
        (已打回待重做, 事件::循环计数(_)) => {
            if 计数 >= 3 {
                Ok(循环超限升级)
            } else {
                Ok(待实现)
            }
        }
        _ => Err(错误::非法转移),
    }
}
```

## 四、不可跳层不可反序的机械校验

```rust
fn 校验不可跳层(当前: 流水线阶段, 下一: 流水线阶段) -> bool {
    let 序列 = vec![
        待化要求, 化要求中, 待设计, 设计中, 待实现,
        实现中, 待验收, 验收中, 待终裁, 终裁中, 已定档,
    ];
    let 当前_索引 = 序列.iter().position(|s| s == &当前).unwrap();
    let 下一_索引 = 序列.iter().position(|s| s == &下一).unwrap();
    下一_索引 == 当前_索引 + 1
    || (当前 == 验收中 && 下一 == 已打回待重做)
    || (当前 == 已打回待重做 && 下一 == 待实现)
    || (当前 == 已打回待重做 && 下一 == 循环超限升级)
}
```

## 五、事件落点

每个状态转移触发对应事件：
- `化要求完成` → 事件流记录意图声明 + decided_by
- `设计开始` → 事件流记录设计阶段
- `验收打回` → 事件流记录打回原因 + 改进建议
- `定档完成` → 事件流记录定档（frozen outcome）
