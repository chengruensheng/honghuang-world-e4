| # | 项 | 脚本 | 标准 |

| 7 | **依赖审查** | `验证-依赖.ps1` | `cargo deny check` 通过 |

### 8. 验证-无src目录.ps1
```powershell
$结果 = Get-ChildItem -Path . -Recurse -Directory -Force |
    Where-Object { $_.Name -eq "src" -or $_.Name -eq "tests" -or $_.Name -eq "scripts" }
if ($结果.Count -gt 0) {
    Write-Host "发现平铺目录："
    $结果 | ForEach-Object { Write-Host $_.FullName }
    exit 1
}
exit 0
```

### 9. 验证-无空目录.ps1
```powershell
Get-ChildItem -Path . -Recurse -Directory -Force |
    Where-Object { (Get-ChildItem $_.FullName -Force | Measure-Object).Count -eq 0 } |
    ForEach-Object { Remove-Item $_.FullName -Recurse -Force }
exit 0
```

### 10. 验证-临时目录.ps1
```powershell
$临时目录 = "临时文件夹"
if (Test-Path $临时目录) {
    Get-ChildItem $临时目录 -Recurse -Force -ErrorAction SilentlyContinue |
        Where-Object { -not $_.PSIsContainer } |
        ForEach-Object { Remove-Item $_.FullName -Force -ErrorAction SilentlyContinue }
    $剩余 = Get-ChildItem $临时目录 -Force -ErrorAction SilentlyContinue
    if ($剩余.Count -gt 0) { Write-Host "临时目录有残留"; exit 1 }
}
exit 0
```
