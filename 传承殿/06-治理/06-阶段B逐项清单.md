# 阶段 B 逐项清单

> 决策锚：`260830-阶段B后续标准`、`260829-记忆架构契约`。
>
> 本清单把 100 项任务队列的九块语义覆盖展开为可逐项证伪的验收条目。勾选不以“代码看起来存在”为准，而以命题后的验证动作和输出为准。阶段 B 的共同门槛是：一键全验 17/17、真实 API 可复现且产出评分 100/100、任务债务为 0、每项有可追溯证据。

## 验收约定

- [ ] 表示该项需要在本轮验收中核对；已有代码或单测只能作为对应证据，不能替代真实验收。
- “真实”指真实 HTTP/API 链路，不得用 模拟冒充真实模型；仅测试确定性纯函数的条目可使用单元测试。
- 命题中写出的退出码、事件名、字段名和数量都是失败判据；任一不满足即该项未完成。
