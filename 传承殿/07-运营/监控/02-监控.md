# 02-监控.md

> **运营层·监控**——运行时状态的可观察性。

## 一、哲学层（为什么）

为什么需要监控？因为**没有监控就没有早期预警**。

- 事后查日志 → 错失最佳响应时机
- 实时监控 → 异常立即告警 → 提前介入

司衡基线 3（人类只看异常）：监控必须把异常**主动顶到界主**，不让界主主动查。

## 二、概念层（是什么）

### 4 类指标

| 类别 | 指标 | 阈值 |
|:--|:--|:--|
| **可用性** | 健康检查通过率 | > 99% |
| **性能** | P95 延迟 | < 5s |
| **正确性** | 决策可证伪率 | > 80% |
| **资源** | 内存 / CPU | < 80% |

### 告警分级

- **P0（紧急）**：服务不可用 → 立即通知界主
- **P1（重要）**：性能降级 → 5 分钟内通知
- **P2（普通）**：资源预警 → 30 分钟内通知
- **P3（提示）**：信息类 → 仅记录不通知
