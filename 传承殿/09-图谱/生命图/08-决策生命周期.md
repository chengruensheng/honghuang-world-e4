# 08-决策生命周期

> 生命图——决策从 1/3 提案到 3/3 拍板再到永久归档的完整生命周期。

## 一、生命周期

```mermaid
stateDiagram-v2
    [*] --> 1-3提案: 发现问题 / 新需求
    1-3提案 --> 2-3审阅: 写出 ≥ 3 个备选方案 + 哲学锚
    2-3审阅 --> 2-3审阅: 列 falsifiable + 时间窗口
    2-3审阅 --> 2-3审阅: 找上游决策 + 哲学锚
    2-3审阅 --> 3-3拍板: 界主拍板
    3-3拍板 --> 实施: decided_by 必填人类标识符
    实施 --> 验证: falsifiable 验证
    验证 --> 通过: 时间窗口到 + 命题成立
    验证 --> 失败: 命题证伪
    通过 --> 永久归档: 保留决策文档
    失败 --> 新决策: 写新决策覆盖
    永久归档 --> [*]
    新决策 --> 1-3提案
```

## 二、3 个阶段详解

### 阶段 1（1/3 提案）

- 输入：发现的问题或新需求
- 输出：决策草案 + ≥ 3 个备选方案
- 字段：id, title, stage=1/3
- 不需要：decided_by, falsifiable

### 阶段 2（2/3 审阅）

- 输入：阶段 1 草案
- 输出：补充的 falsifiable + 上游依赖 + 哲学锚
- 字段：falsifiable, upstream, implements
- 不需要：decided_at, decided_by

### 阶段 3（3/3 拍板）

- 输入：阶段 2 完整草案
- 输出：可执行的决策
- 必填字段：decided_by（人类标识符）, decided_at（日期）
- 拍板后：决策不可改除非新决策覆盖
