## 三、实施任务（5 天）

### Day 1：重写 jiyi_chengzai_fu enum（修阶段1的错）

**修正点**（来自 `02-概念/记忆/03-记忆.md § 2.1.2`）：

| 错（阶段1残留） | 正（文档） |
|:--|:--|
| `enum 格位 { 现状, 期望, 障碍, 路径, 评估, 演化 }` | `enum 阶段 { 提案, 审阅, 拍板, 实施, 验收, 归档 }` |
| 取值借自项目管理框架（OKR/SWOT） | 取值是 6 生命周期维度（命名学：决策流转的 6 个状态） |
| 「格位」是 6 元集合（错位命名） | 「格位」= 范畴 × 阶段 的笛卡尔积（36 个具体位置） |

**正确结构**：

```rust
pub enum 范畴 { 目标, 规则, 自我, 程序, 世界, 经历 }
pub enum 阶段 { 提案, 审阅, 拍板, 实施, 验收, 归档 }
pub struct 格位 { pub 范畴: 范畴, pub 阶段: 阶段 }
pub const 格位总数: usize = 6 * 6;
```

**单元测试**：范畴枚举 6 项、阶段枚举 6 项、格位总数 36、笛卡尔积无重复

### Day 2：四维正交 + 本质判定程序化

来自 `04-设计/数据模型/01-记忆.md § 三`：

- `判定本质校验()`: 本质 × 阶段合法性矩阵 + 内容关键词启发式
- `本质阶段合法性()`: 6×6 矩阵非均匀密度
  - 目标 → 提案|拍板|实施（不能归档）
  - 规则 → 提案|审阅|拍板（不能实施）
  - 自我 → 提案|拍板（很少变更）
  - 程序 → 提案|审阅|实施|验收（常实施）
  - 世界 → 提案|验收（外部状态）
  - 经历 → 提案|实施|验收|归档（可归档）
- `内容本质一致()`: 启发式关键词匹配（TODO/必须/我是/代码/环境/已发生）
- 写入接口强制 4 维正交（decided_by 必填）

**单元测试**：每个合法性矩阵分支 + 关键词匹配 + decided_by 缺失报错

### Day 4：加载协议（MUST/MIXED/OPTIONAL）+ 拼全息图

来自 `02-概念/记忆/03-记忆.md § 2.6`：

```rust
pub enum 加载档位 { MUST, MIXED_核心, OPTIONAL }

pub fn 格位_加载档位(范畴, 阶段) -> 加载档位 {
    match (范畴, 阶段) {
        (规则, _) => MUST,                  // 规则/全部 6 格位
        (自我, _) => MUST,                  // 自我/全部 2 格位
        (程序, 拍板) => MIXED_核心,
        (目标, 拍板) => MIXED_核心,
        _ => OPTIONAL,                       // 其余 22 格位
    }
}
```

**会话阶段枚举**：开始 / 任务接收 / 实施 / 验收 / 故障

**拼全息图协议**：

| 会话阶段 | 必拼 (MUST) | 选拼 (按任务) | 配方 |
|:--|:--|:--|:--|
| 开始 | 规则/全部 + 自我/全部 | — | 风格+身份 |
| 任务接收 | + 目标/拍板 | + 目标/审阅 | 我要去哪+本次往哪 |
| 实施 | + 程序/拍板 | + 程序/审阅 + 程序/实施 | 工具+怎么用 |
| 验收 | + 规则/验收 + 自我/拍板 | + 经历/归档 | 红线+历史教训 |
| 故障 | + 自我/拍板 + 规则/拍板 | + 经历/归档(全量) | 身份+红线+教训 |

**硬约束**：拼后总行数 ≤ 24

**单元测试**：
- 每个 (范畴, 阶段) 组合的加载档位与文档一致
- 5 个会话阶段各自的拼全息图行数 ≤ 24
- 加载档位变更函数 decided_by + 决策 ID 必填

### Day 5：存储后端 + 三维检索 + 端到端

- **存储 trait** `记忆存储`: 读/写/删/查_维度（接口）
- **内存后端** `内存存储`: `HashMap<记忆ID, 记忆条目>`（先实现内存，SQLite/JSONL 留接口）
- **三维检索**:
  - `按范畴阶段()`: 同时给范畴 + 阶段（命中 36 格位之一）
  - `按档位()`: 命中经档/权档/行档之一的所有条目
  - `按来源()`: 命中 代码/LLM/人类 之一的所有条目
  - `四维拼装()`: 同时给 4 个维度精确检索
- **集成测试**:
  - 36 格位利用率 ≥ 80%：每格位至少写 1 条 → 验证读取
  - 三维检索 100% 命中：写 100 条 → 各种维度组合检索 → 100% 命中
