## 二、技术规范

### 2.1 非 ASCII 模块名桥接

Rust 模块名非 ASCII 时必须用 `#[path]` 指定文件路径：

```rust
// 入口.rs
#[path = "类型_定义_殿/殿.rs"]
pub mod 类型_定义_殿;

#[path = "存储_操作_殿/殿.rs"]
pub mod 存储_操作_殿;
```

殿内继续用 `#[path]` 桥接阁：

```rust
// 类型_定义_殿/殿.rs
#[path = "../格位_阁/阁.rs"]
pub mod 格位_阁;
```

### 2.2 入口.rs 模板

```rust
//! X - 府（一句话本质）
//!
//! 决策锚：260827-0338-殿阁园重构 + 原决策锚
//! 关联文档：原关联文档

#![allow(non_snake_case)]
#![allow(dead_code)]

// === 各殿 ===
#[path = "Y_殿/殿.rs"]
pub mod Y_殿;

// === 顶层导出 ===
pub use Y_殿::某结构;
```

### 2.3 目录结构

```
X - 府/
├── Cargo.toml
├── 入口.rs
├── Y - 殿/
│   ├── 殿.rs          ← pub mod 各阁 + pub use
│   └── Z - 阁/
│       ├── 阁.rs      ← pub mod 各园
│       └── W - 园/
│           └── 园.rs  ← 实际实现
```

## 三、实施顺序

### 第一步：目录命名合规（全局，1 个 commit）

1. 用 `git mv` 重命名所有域/府目录（保留 git 历史）
