## 七、风险与回滚

- 风险 1：trait 拆分到「方法-契约-阁/方法-契约-园」语义薄弱（trait 方法签名放园但无实际代码）——降级方案：把方法-契约-阁 合并到接口-定义-阁
- 风险 2：7 个 crate 切分后 #[path] 桥接 import 深度增加，编译错误增多——沿用调遣模式，每 crate cargo check 即时反馈
- 回滚：每个 crate 一个独立 commit，失败 git reset --hard HEAD~1
