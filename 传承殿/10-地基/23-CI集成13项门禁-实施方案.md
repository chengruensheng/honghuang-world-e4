## 三、CI 步骤（最终形态）

```yaml
name: 一键全验
on:
  push:    { branches: [main] }
  pull_request: { branches: [main] }
jobs:
  verify:
    strategy:
      matrix: { os: [ubuntu-latest, windows-latest] }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable   # toolchain: 1.75, components: rustfmt, clippy
      - if: matrix.os == 'ubuntu-latest'
        uses: microsoft/powershell@v1          # pwsh: true（ubuntu runner）
      - uses: Swatinem/rust-cache@v2           # 自动探测 target-dir
      - run: cargo fmt --all -- --check
      - run: cargo clippy --workspace --all-targets -- -D warnings
      - run: cargo test --workspace --lib
      - run: bash ./一键全验.sh
```

## 五、风险

- 风险 1：ubuntu runner 中文路径空格 → `actions/checkout@v4` 自动处理；bash `cd "$(dirname "$0")"` 用双引号保护；pwsh 脚本内部 `Set-Location ../..` 无中文问题
- 风险 2：`Swatinem/rust-cache@v2` 对中文 target-dir 缓存键 → 实际 hash 由 cargo 自动算出，与路径无关
- 风险 3：`microsoft/powershell@v1` ubuntu 安装耗时 → 缓存后约 30s/首次，无重大延迟
- 风险 4：cargo fmt / clippy 在 CI 上若不通过 → 暴露在工作流前两步，阻止下游 13 项门禁运行
